## v0.2.3 からの変更

### 画面 (既定の見え方が変わる)
- `video_scale` の既定を、`integer` (整数倍) から `aspect` (4:3 で高さいっぱい) にした (ベアメタル版。Pi 2 は `integer` のまま)。**前の見え方に戻す**には、`pix68k.cfg` に `video_scale=integer` と書く。
- 配布の `config.txt` では、どの機種にも `disable_overscan=1` を書いた。**カーネルだけを入れ替えるときは、`config.txt` の最初の節 (`[pi3]` など) より前に、この 1 行を自分で足す** ([baremetal.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/baremetal.md))。
  ```
  disable_overscan=1
  ```
- Pi 3 で `video_filter=` だけを書いていると、前より処理が重くなる。遅れるときも `video_scale=integer` にする。

### 音を鳴らしたまま変えるミキサー
- X68000 と音を止めずに音量を変えられる。Shift + 設定メニューのキー (Pi 400 は Shift + ラズベリー + M、ホスト版は Shift + F12 でも) で開く。ベアメタル版はブラウザ (`/mixer.html`) からも使える ([settings-menu.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/settings-menu.md))。
- **変わったこと**: Shift を押しながらの設定メニューのキーは、設定メニューではなくミキサーを開く。

### ゲームパッドのボタンの並び
- 設定メニューの Gamepad setup で、ボタンを順に押して並びを決め、`pads.txt` に保存できる (ベアメタル版)。並びの分からないゲームパッドは、キーボードがなくても、ボタンの長押しで始められる (時間の条件は [settings-menu.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/settings-menu.md))。
- Home も Select も割り当てないと、そのゲームパッドでは設定メニューを開けなくなる。

### ふろっぴU君 (ベータ)
- ふろっぴU君 (FUK) につないだ FDD の 2HD のディスクを、XDF のイメージに読み出せる。ベアメタル版 (Pi 4、Pi 400、Pi 5) は `pix68kcli fuk-read --drive 0 disk.xdf`、ホスト版は `--fuk on --fuk-read 0 disk.xdf` ([fuk.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/fuk.md))。
- **注意**: ふろっぴU君の実物では、まだ確かめていない。書き込み禁止にしたディスクで試してほしい。

### カーネルの更新 (試験中)
- `pix68kcli update --check` で配布している版と比べ、`update --no-tryboot` でカーネルだけを更新し、`update --rollback` か Pi の画面の Roll back で前の版に戻す。`--no-tryboot` は必須 ([pix68kcli の README](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/tools/pix68kcli/README.md))。
- **v0.2.3 からの更新には使えない**。この版は zip から手で入れ、次の版から使う。**新しい版が起動しなければ、SD カードをパソコンに入れて `config.txt` の `kernel=` を戻す**ことになる。
- `config.txt` を書いている最中に電源が切れると、`config.txt` が壊れることがある。

### そのほか
- SRAM の起動装置が SRAM のときと、フロッピーディスクのイメージのブートセクタが書き換えられたときに、画面とログで知らせる。`FORMAT` などでも出る。やめるには `boot_warn=off` ([disks-and-scsi.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/disks-and-scsi.md))。
- MIDI の音源を用意できない理由を画面に出す (`MT-32 (no ROM)` など)。

### 既知の問題
- Pi 400 にはまだ正式には対応していない。日本語キーボードの Pi 400 で、英語配列と判定されることがある (`keyboard=pi400jp` と書けば日本語配列になる)。
- Scroll Lock、Application、Menu のどのキーもないキーボード (Pi 400 を除く) では、ベアメタル版のミキサーを画面に開けない。`pix68k.cfg` に `keyboard=pi400us` (日本語配列は `pi400jp`) と書いて起動し直すと、Shift + 左 Windows (Command) + M で開ける。ほかのキーの動きも変わる ([keyboard.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/keyboard.md))。

### 確かめたこと、確かめていないこと
確かめたこと (開発中の版):
- 画面: Pi 3B+、Pi 4、Pi 5 の `aspect` で、フレームの遅れは 0 だった (Pi 3B+ は変わった行だけを写す場合)。
- ミキサー: Pi 3B+ と Pi 5 で、開いても遅れと音の途切れは増えなかった。Pi 400 (英語キーボード) で開いた。Web は Pi 3B+ とパソコンのブラウザ。
- ゲームパッド: Pi 5 と HORIPAD S で、設定、保存、再起動後の保持。
- FUK: Pi 4 と、FUK の動作を再現する Pico 2 W で、ドライブ 0 と 1 のイメージが全バイト一致し、書き込みは 0 回だった。
- 更新: Pi 400 (英語キーボード、SD カードから起動) で、`update` と同じ順の要求を送るスクリプトで更新し、`--rollback`、設定メニュー、起動メニューで前の版に戻した。

確かめていないこと:
- 画面: Pi 3B と Pi 400 での速さ、テレビ。
- ミキサー: ベアメタル版の実物のゲームパッドとマウス、ホスト版の実際の操作、スマートフォン、Pi 2 / 4 / 400 での負荷。
- ゲームパッド: 長押しで始めること、ほかのゲームパッド、Pi 5 以外。
- FUK: 実物、Pi 400 と Pi 5 での読み出し。
- 更新: 配布の版を相手にした `update`、Pi 400 以外。書き換えの警告と MIDI の表示: 実機。

## Changes since v0.2.3 (English)

### Display (the default appearance changes)
- The default `video_scale` is now `aspect` (4:3, full height) instead of `integer` (integer scaling) on the bare-metal build (the Pi 2 stays at `integer`). **To go back to the old appearance**, write `video_scale=integer` in `pix68k.cfg`.
- The `config.txt` in the package now has `disable_overscan=1` for every model. **If you replace only the kernel, add this line to your `config.txt` before the first section (such as `[pi3]`)** ([baremetal.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/baremetal.md); the linked documents are in Japanese).
  ```
  disable_overscan=1
  ```
- On a Pi 3 with only `video_filter=` written, processing is heavier than before. If frames are late, use `video_scale=integer` as well.

### Mixer that works while the sound plays
- Changes the volume without stopping the X68000 or the sound. Shift + the settings menu key opens it (Shift + Raspberry + M on the Pi 400; also Shift + F12 on the host build). The bare-metal build also has a browser page, `/mixer.html` ([settings-menu.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/settings-menu.md)).
- **Changed**: the settings menu key with Shift now opens the mixer instead of the settings menu.

### Gamepad button layout
- Gamepad setup in the settings menu sets the layout by pressing the buttons in order and saves it to `pads.txt` (bare-metal build). For a gamepad with an unknown layout, you can also start it without a keyboard by holding a button (for the timing, see [settings-menu.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/settings-menu.md)).
- If neither Home nor Select is assigned, that gamepad cannot open the settings menu.

### Floppy-U-kun (beta)
- A 2HD disk in an FDD connected to a Floppy-U-kun (FUK) can be read into an XDF image: `pix68kcli fuk-read --drive 0 disk.xdf` on the bare-metal build (Pi 4, Pi 400, Pi 5), `--fuk on --fuk-read 0 disk.xdf` on the host build ([fuk.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/fuk.md)).
- **Caution**: this has not been tested with a real Floppy-U-kun. Please try it with a write-protected disk.

### Kernel update (experimental)
- `pix68kcli update --check` compares with the released version, `update --no-tryboot` updates only the kernel, and `update --rollback` or Roll back on the Pi's screen goes back to the previous version. `--no-tryboot` is required ([pix68kcli README](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/tools/pix68kcli/README.md)).
- **It cannot update from v0.2.3.** Install this version by hand from the zip, and use `update` from the next version. **If the new version does not boot, you must put the SD card in a PC and change `kernel=` in `config.txt` back.**
- If the power fails while `config.txt` is being written, the file may be damaged.

### Others
- A message on the screen and in the log tells when the SRAM boot device is SRAM and when the boot sector of a floppy disk image is rewritten. It also appears for `FORMAT` and the like. Write `boot_warn=off` to turn it off ([disks-and-scsi.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/disks-and-scsi.md)).
- The screen shows why a MIDI sound source is not available (`MT-32 (no ROM)` etc.).

### Known issues
- The Pi 400 is not officially supported yet. On a Pi 400 with a Japanese keyboard, the keyboard may be detected as the English layout (write `keyboard=pi400jp` to use the Japanese layout).
- With a keyboard that has none of the Scroll Lock, Application and Menu keys (except on the Pi 400), the on-screen mixer of the bare-metal build cannot be opened. With `keyboard=pi400us` in `pix68k.cfg` (`pi400jp` for a Japanese layout) and a restart, Shift + Left Windows (Command) + M opens it. Other keys also behave differently ([keyboard.md](https://github.com/j3tm0t0/pix68k/blob/v0.2.4/docs/keyboard.md)).

### Tested and not tested
Tested (on development versions):
- Display: no late frames with `aspect` on a Pi 3B+, Pi 4 and Pi 5 (the Pi 3B+ copying only changed lines).
- Mixer: no increase in late frames or audio dropouts with it open on a Pi 3B+ and a Pi 5. It opened on a Pi 400 (English keyboard). The web page on a Pi 3B+ with a PC browser.
- Gamepad: setup, saving and keeping the layout after a restart, on a Pi 5 with a HORIPAD S.
- FUK: on a Pi 4 with a Pico 2 W that reproduces the FUK's behavior, the images of drives 0 and 1 matched in every byte with 0 writes.
- Update: on a Pi 400 (English keyboard, booted from an SD card), updating with a script that sends the same requests in the same order as `update`, and going back with `--rollback`, the settings menu and the boot menu.

Not tested:
- Display: speed on the Pi 3B and Pi 400, TVs.
- Mixer: a real gamepad and mouse on the bare-metal build, real operation of the host build, smartphones, the load on the Pi 2 / 4 / 400.
- Gamepad: starting by holding a button, other gamepads, models other than the Pi 5.
- FUK: a real one, and reading on the Pi 400 and Pi 5.
- Update: `update` with released versions, models other than the Pi 400. The boot warnings and the MIDI messages: on real hardware.
