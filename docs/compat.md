# ゲームとソフトの動作の記録

市販のゲーム、同人ゲーム、ツール、ドライバを pix68k で動かした結果を、PR と issue の記録から集めた一覧。
記録にあることだけを書いた。表にない組み合わせは、試していないか、記録が残っていない。
ゲームやドライバのイメージ、ROM はリポジトリに入れていない。

## 列の意味

- **種類**: 市販、同人など
- **媒体**: FD はフロッピーディスクのイメージ (XDF など)、SASI / SCSI の HD はハードディスクのイメージ (HDF / HDS)
- **機種 / CPU**: 68000 10MHz / 16MHz (X68000 XVI 相当)、X68030 (68030 25MHz)、060turbo (68060 50MHz / 75MHz)。クロックが記録にないものは「68000」のように CPU だけを書く
- **環境**
  - ホスト版: Mac で動かした `build/pix68k` (SDL2) か、試験用の `x68k_boot`
  - Pi 3 Linux: Pi 3B+ の Linux の上で `machine_bench` を動かしたもの (ベアメタル版ではない。値は実時間の何倍か)
  - Pi 3 / Pi 4 / Pi 5: ベアメタル版を実機で動かしたもの (Pi 3 は Pi 3 Model B+、Pi 5 は 8GB)
- **時点**: 確かめたときの PR か issue。未マージの PR を入れて確かめたものは「未マージ」と書く
- **結果**
  - 動く: 止まらず、メモに書いた範囲まで動く
  - 遅れあり: 動くが、遅れたフレーム (1 フレームの処理が間に合わなかった回数) や音の途切れが 1 回でも出る
  - 遅い: 実時間に届かない
  - 止まる: 途中で止まる、エラーになる
- 遅れたフレームの数は、ベアメタル版が 10 秒ごとにログ (HTTP の `/log` と syslog) に出す `frames:` の行の値。
  10 秒で約 555 フレーム
- 記録にない欄は「記録なし」と書く
- Pi 3 の音は HDMI から録って波形が出ていることを確かめた。耳で聞いて乱れがないかは、まだ確かめていない (#104)

## 足し方

確かめたら、この表に 1 行足す。同じタイトルでも、機種 / CPU、環境、時点が違えば別の行にする。
結果が変わったら古い行は消さずに残し、新しい行を足す。
メモには、どこまで動かしたか (タイトル画面、デモ、操作して遊んだか) と、遅れたフレームなどの数を書く。
未マージの PR で確かめた行は、その PR がマージされたら「(未マージ)」を外す。マージ前の版で測った行は、分かるなら時点の欄にコミットか日付も書く。
